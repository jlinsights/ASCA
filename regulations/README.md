## 번역본 (영어·일본어·중국어)

`i18n/en`, `i18n/ja`, `i18n/zh`(번체)에 9개 문서의 참고용 번역이 있습니다.
화면에서 언어를 바꾸면 번역본이 보이고 "한국어 원문이 우선한다"는 안내가
붙습니다. 조 번호와 앵커(`#a6`)는 원문과 같습니다. 용어와 파일 형식은
[i18n/GLOSSARY.md](./i18n/GLOSSARY.md).
`lib/regulations/__tests__/translations.test.ts` 가 장·조·표 구조가 원문과
같은지 확인합니다.

## 개정 방법

1. 개정마다 브랜치를 따로 만들고 PR로 올립니다 (예:
   `regulations/2026-11-dues-art3`).
2. 해당 파일을 수정하고 머리말의 `effective_note`에 시행일·개정 내용을 적습니다.
3. 같은 PR에서 `i18n/{en,ja,zh}` 의 같은 조문도 고칩니다 (구조가 다르면 테스트가
   실패합니다).
4. [CHANGELOG.md](./CHANGELOG.md) 맨 위에 의결 기관·날짜·시행일·내용을 한 항목
   추가합니다.
5. 커밋 메시지와 PR 제목에 의결 기관과 날짜를 적습니다 (예:
   `회비 규정 제3조 개정 (2026-11-20 이사회 의결)`).
6. 머지 후 태그를 붙여 시점별 원문을 고정합니다 (예: `regulations-2026-11-20`).
7. 정관 변경은 총회 재적 회원 3분의 2 찬성과 문체부 허가가 필요합니다 (정관
   제40조).
