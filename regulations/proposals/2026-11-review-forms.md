# 운영·심사 규정 별표 1~4 서식 초안

- 작성일: 2026-11-08
- 상태: 합의한 정비 방향을 기록하기 위한 운영 서식 초안, 의결·공포 전
- 관련: [운영·심사 정비 초안](./2026-11-operation-review-revision.md)

이 서식은 내부 검토용이며 현행 공개 서식을 대체하지 않는다. 빈칸에 실제 행사와
심사 기록을 기재한다. 본인 심사자료 제공 방식과 대외 공개 범위는 운영·심사 정비
초안 2.19에 따른다. 보관·접근 관리 등 운영 세부사항은 추가 확인한다.

## 별표 4. 심사결과종합표

### 4-1. 작품별 유효 채점·제외 내역

| 심사번호 | 위원 관리번호 | 항목 1 | 항목 2 | 항목 3 | 항목 4 | 총점 | 채점 상태·집계 반영 여부·근거 |
| -------- | ------------- | ------ | ------ | ------ | ------ | ---- | ----------------------------- |
|          |               |        |        |        |        |      |                               |

작품별 유효 채점위원은 최소 5명이다. 제척 등으로 무효인 점수와 총점 최고·최저 각
1개 제외를 구분하여 기록한다. 최고·최저 동률이면 사전 추첨 우선순위에 따르고,
같은 위원을 중복 제외하지 않는다. 대체위원 보강·재채점은 관련 기록을 연결한다.

### 4-2. 평균·동점·등급 집계

| 항목                                         | 기재 내용 |
| -------------------------------------------- | --------- |
| 작품 심사번호·부문                           |           |
| 유효 채점위원 수·원점수표 참조               |           |
| 최고·최저 제외 위원·점수·추첨 순위 참조      |           |
| 제외 후 남긴 위원 관리번호·인원              |           |
| 남긴 위원 총점 합계 / 인원                   |           |
| 판정용 평균: 분자·분모 또는 반올림 전 계산값 |           |
| 표시용 평균: 소수점 둘째 자리                |           |
| 동일 잔여 위원의 항목 4 합계 / 인원          |           |
| 동일 잔여 위원의 항목 3 합계 / 인원          |           |
| 일반 순위·입상 등급·후보 여부                |           |
| 동점 재심의·표결 기록 참조                   |           |
| 집계자·검산자 확인                           |           |

중간 계산을 반올림하지 않는다. 표시용 평균은 소수점 셋째 자리에서 반올림하되,
순위·등급·동점 판정은 반올림 전 계산값을 사용한다.

### 4-3. 대상·일반 동점 표결 기록

| 항목                                              | 기재 내용                              |
| ------------------------------------------------- | -------------------------------------- |
| 표결 구분                                         | 대상 단독 / 대상 복수 후보 / 일반 동점 |
| 대상 후보 심사번호·90점 이상 여부                 |                                        |
| 모든 후보에 이해관계 없는 참여 위원 관리번호·인원 |                                        |
| 참여 위원 5명 이상·제척·기피 확인                 |                                        |
| 재심의 내용·표결 회차                             |                                        |
| 후보별 찬성·득표 수 및 반대·기권·무효 내역        |                                        |
| 참여 위원 과반수 요건 충족 여부                   |                                        |
| 재심의·재투표 또는 선정·미선정 결과와 근거        |                                        |
| 기록자·위원장 확인                                |                                        |

대상 후보가 없으면 미선정으로 기록한다. 단독 대상 후보는 과반수 찬성을 얻어야
선정하며, 얻지 못하면 미선정으로 기록한다. 복수 대상 후보 또는 일반 동점
표결에서 과반수 결정을 얻지 못하면 재심의·재투표 기록을 연결한다.
