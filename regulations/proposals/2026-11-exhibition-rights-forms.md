# 전시 작품 이용 명세·선택 동의·철회 처리 서식 초안

- 작성일: 2026-11-08
- 근거:
  [전시 작품 이용허락·아카이브 정비 초안](./2026-11-exhibition-rights-revision.md)
- 상태: 사용자 확인을 받은 정비 방향을 옮긴 내부 운영 서식 초안
- 의결일·공포일·시행일: 미정

이 문서는 실제 접수에 적용하기 전의 초안이다. 빈칸은 해당 전시·작품·연구의 실제
내용으로 채운다. 선택 동의는 미리 선택하지 않으며, 아카이브 공개와 AI 연구를
각각 별도로 확인한다. 정관·현행 규정 원문·공개 페이지는 변경하지 않는다.

- 별도로 계약한 전시 도록 이용과 심사·수상 기록 관리는 각각의 이용 근거·목적·
  관리 기준에 따라 처리한다.
- 출품자·소장자의 연락처·주소·거래내역은 공개하지 않는다.

## 3. AI 진위감정 연구 별도 선택 동의 및 외부 제공 명세

아카이브 공개 동의에 포함시키지 않고 별도로 작성한다. 외부 비영리 공동연구는
제공 기관·목적·자료 범위·기간을 명시한 별도 동의와 연구계약을 모두 확보한다.

| 항목                                                  | 동의·자료 제공 전에 기입할 내용 |
| ----------------------------------------------------- | ------------------------------- |
| 연구 과제명 / 협회 책임자                             |                                 |
| 목적                                                  | 협회의 비영리 진위감정 연구     |
| 연구 시작일·종료일                                    |                                 |
| 대상 작품·이미지 식별번호 / 자료 범위·이용 방법       |                                 |
| 외부 비영리 공동연구 해당 여부 / 기관명·담당자        |                                 |
| 외부 제공 목적·자료 범위·제공 기간                    |                                 |
| 별도 외부 제공 동의·연구계약 문서 번호                |                                 |
| 삭제·재학습·사용 중단 등 실행 가능한 철회 조치와 대상 |                                 |
| 학습 완료 모델·연구성과물에 대한 철회 조치·기한       |                                 |
| 조치별 담당자·실행계획 / 외부 기관의 이행 확인 방법   |                                 |
| 연구자료에서 제외할 불필요한 개인정보                 |                                 |

- 외부 상업용 AI 학습을 위한 데이터 판매·제공은 금지한다.
- 기간 연장 또는 목적 변경 시 새 동의를 받는다.
- 자료 제공 전에 실행 가능한 철회 조치·기한을 동의서·연구계약에 명시하고
  실행계획을 확보한다. 빈칸을 채우지 않은 포괄 동의로 제공하지 않는다.
- 권리자는 언제든 철회할 수 있다. 접수 즉시 신규 이용을 중단하고, 철회일부터
  14일 이내에 조치 결과 또는 구체적인 이행 일정을 통지한다.
- 위 이행 일정 통지는 아카이브의 온라인 공개 중단 기한을 연장하지 않는다.

## 5. 기존 게시 작품의 권리 확인 대장

작품마다 다음 항목을 작성한다. 이미지 이용과 심사·수상 기록 관리를 구분한다.

| 항목                                             | 기입란                                                            |
| ------------------------------------------------ | ----------------------------------------------------------------- |
| 작품 식별번호·작품명 / 현재 게시 위치            |                                                                   |
| 기존 계약·동의 문서 또는 법령상 이용 근거        |                                                                   |
| 현재 공개 목적·매체·기간·범위와 근거의 일치 여부 |                                                                   |
| 저작재산권자·대리권 / 제3자 사진 이용권한 확인   |                                                                   |
| 판단                                             | □ 확인된 범위에서 공개 유지　□ 근거 불명확으로 이미지 일시 비공개 |
| 비공개 처리일·대상 / 필요한 권한 확인·추가 동의  |                                                                   |
| 보완 자료·확인 결과 / 재공개 범위·처리일         |                                                                   |
| 별도로 관리하는 심사·수상 기록의 근거·관리 기준  |                                                                   |
| 담당자·확인일                                    |                                                                   |

기존 게시 사실만으로 장기 공개 또는 AI 연구 동의를 추정하지 않는다. 근거가
불명확한 이미지는 일시 비공개하고, 권한 확인·추가 동의 등 필요한 보완을 마친 뒤
확인된 범위에서 다시 공개한다.

## 6. 운영 적용 전 기입·확인할 사항

- 전시 계약의 실제 매체·기간·범위와 작가 표시·편집 승인 내용
- 아카이브 공개 위치·항목, 철회 접수 채널·담당자
- 연구 과제별 기관·기간·자료 범위·실행 가능한 철회 조치와 계약
- 기존 게시 작품의 점검 일정 및 의결·공포·시행에 따른 경과조치

실제 권리자 동의 수집·기존 이미지 점검·공개 중단이나 시스템 구현을 완료했다는
의미는 아니다.
