## 통합 방식

규정별 본칙 조문을 통합하고 바꾸지 않은 조문은 현행 내용을 유지했다. 회원·회비
초안의 정책 합의는 조문으로 작성했고, 다른 초안의 부분 개정 문안은 해당 조문에
합쳤다. 기존 부칙의 시행일·경과조치는 원문을 참조하며 새 시행 사실을 만들지
않았다.

문구가 겹치는 경우에는 이후 합의한 구체적 기준과 맞췄다. 개인 도록 취소 특칙과
협회 귀책 환급, 미납 완납과 다른 정지 사유 복원, 전시·홈페이지의 서로 다른 작품
수 산정, 기본 플립북과 유료 추가 옵션의 관계를 조문에 연결했다. 상세 조정 내역은
검토 결과에 기록했다.

정책 확인을 받지 않은 날짜·금액·보존기간·운영 방법은 임의로 확정하지 않았다.
의결·공포 전에는 기존 개별 초안과 이 통합안을 모두 내부 검토 자료로 관리한다.

## 다음 확정 작업

미확정 목록에 대한 정책·운영 확인과 법률·세무 검토 결과를 반영한 뒤 최종
의결안을 작성한다. 의결 기관·일자·공포일·시행일이 확인되면 현행 원문·참고
번역·안내·개정 이력을 같은 기준으로 갱신한다. 이 자료 작성만으로 원문 반영이나
실제 접수·정산· 권리 확인 시스템의 운영을 완료한 것은 아니다.
