# 통합 검토 결과 및 미확정 사항

- 검토일: 2026-11-08
- 범위: 현행 규정과 사용자 확인을 받은 정비 초안 사이의 문구·번호·금액·절차 대조
- 상태: 내부 초안 검토. 법률·세무의 최종 적합성 확인이나 실제 운영 확인은 아님

## 1. 통합 시 정리한 사항

| 항목                  | 통합 결과                                                                                       |
| --------------------- | ----------------------------------------------------------------------------------------------- |
| 안내와 규정의 관계    | 자격·요건 안내는 요약문으로 유지하며 개별 규정의 실제 시행과 연결                               |
| 정회원·면제·명예작가  | 면제 정회원의 권리 유지와 명예회원의 의결권 없음·추대 동의를 구분                               |
| 회비 복원과 특별선임  | 회비 완납이 활동 미이행·징계까지 해소한다는 해석을 막도록 선임 규정 제11조 제6항 연결           |
| 전시 최소 작품 수     | 개인전·독립 부스는 실제 10점 이상, 공동 부스는 전체 수, 홈페이지 혜택은 작가별 실제 수          |
| 누적 요금             | 기본 10점과 추가 구간 요금을 합산; 혼합 부스는 회원가 총액에 비회원 1점당 2만원 가산            |
| 표구·공동 도록        | 표구비에 공동 도록 제작 실비 포함, 예외 작품은 수록 지면별 실비; 중복 청구 방지                 |
| 공동 도록 배부        | 도록 개정안의 전시 참여 정회원 1권 기준으로 안내 표현 통일; 무료 대상의 새로운 확대는 하지 않음 |
| 전시 비용과 무료 지원 | 전시 규정 제4조의 전액 부담 표현을 무료 기본 편집·플립북 및 비용 포함 범위와 연결               |
| 개인 도록 취소 특칙   | 작가 개인 사정의 완료 업무·발주 실비와 협회 귀책·불가항력·연기의 사유별 환급을 연결             |
| 홍보 대행 환급        | 현행 제9조의 홍보 대행 계약 적용 범위를 통합 환급 조문에도 유지                                 |
| 판매 정산             | 작품별 모든 요건 충족일 기준 14일, 구매자 환급 3영업일과 구분; 수수료·세금·분쟁금 분리          |
| 심사 인원             | 공모전 채점 5명, 선임 5명 및 외부 요건, 감정 3명, 일반 독립 이의 검토 3명을 혼용하지 않음       |
| 심사 집계             | 총점 최고·최저 각 1명 제외, 동률 추첨 순서, 남긴 동일 위원 항목 평균과 반올림 전 순위 유지      |
| 아카이브              | 비영리 공개 원칙을 작품별 권한·선택 동의 범위와 연결; 기존 게시가 새 동의를 대신하지 않음       |
| AI 철회와 온라인 공개 | AI 조치·이행 일정 통지가 온라인 공개 중단 14일을 연장하지 않도록 연결                           |
| 이의제기 명칭         | 통합안의 인용을 실제 문서명 「이의제기 처리 규정」으로 통일                                     |
| 조문 번호             | 기존 번호는 유지하고 가지번호 신설; 홈페이지 제10조 재배치에 따른 제5항 인용 수정               |

통합 본문의 조정은 기존 정책 합의를 조문화하거나 상호 인용을 맞춘 것이다. 개별
초안은 합의 근거로 보존하며, 통합 후 새로 확정된 의결·시행 사실을 추가하지
않았다.

## 2. 전문가 확인이 필요한 항목

| 대상                  | 확인 사항                                                                             | 현재 처리                                                                     |
| --------------------- | ------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 감정 규정 제8조       | 필수 기록·저작권 이용허락·개인정보 동의의 관계, 간주 동의 삭제 및 선택 이용·철회 문안 | 합의 방향을 조문화한 초안으로 표시; 전문가 확인 전 확정·공개 반영하지 않음    |
| 감정 보증·책임        | 보증 범위·재검토·재발행과 면책 문구의 적용                                            | 고의·중과실 책임 배제 금지 방향의 초안; 최종 계약 문안 검토 필요              |
| 판매·취소 세무        | 소득 구분·실제 세금 공제·증빙 발행·정산 취소 시 정정                                  | 현행 법령 처리 원칙 유지; 세율·원천징수율을 임의로 넣지 않음                  |
| 반품·환급 계약        | 현장·통신판매별 법 적용, 강행 기준과 계약상 추가 보장                                 | 앞선 법령 확인 메모를 근거로 한 협회 운영 기준 초안; 실제 계약 형태 확인 필요 |
| 정관 기재 지부의 폐지 | 정관에 기재된 지부의 변경·폐지에 필요한 절차                                          | 적법한 폐지 결정 후 정산만 조문화; 정관 변경 절차를 대체하지 않음             |

앞선 법령 확인의 출처·시점·범위는
[감정 초안](../2026-11-appraisal-certificate-revision.md),
[판매 초안](../2026-11-exhibition-sales-revision.md),
[권리 이용 초안](../2026-11-exhibition-rights-revision.md)의 확인 메모를
참조한다. 이번 통합 작업에서 별도의 법령 최신성 재확인은 수행하지 않았다.

## 3. 정책·운영 측면의 미확정 항목

| 항목                    | 남은 확인                                                                                     |
| ----------------------- | --------------------------------------------------------------------------------------------- |
| 적용 일정               | 의결·공포·시행일 및 [부칙·경과조치](./TRANSITION.md)의 최초 적용 대상                         |
| 실제 원가·요금          | 누적 출품비의 운영 원가 적정성, 표구비의 공동 도록 포함 원가, 감정 기본료·난이도별 실제 요금  |
| 개인정보·동의 기록 보존 | 목적별 항목·기간·접근 권한·파기 방법; 연락처·신청서를 일괄 영구 보존하지 않는다는 원칙만 합의 |
| 심사 운영               | 예비·대체위원 보강 시 추첨 우선순위, 원자료 보관·접근, 본인 자료 제공 담당·방식               |
| 독립 재검토             | 분야별 독립 위원의 위촉·운영 및 최종 의결기구로의 보고 방법                                   |
| 계약·정산 서식          | 전시·판매·제작·홈페이지별 실제 계약·정산서와 적용 범위 명시                                   |
| 홍보 서비스 범위        | 출품비에 포함된 기본 홍보와 별도 유료 홍보 대행의 범위를 실제 계약·안내에서 구분              |
| 기존 자료 점검          | 기존 동의·게시 이미지·보증서 원장·연구 제공 자료의 사실 확인과 보완 일정                      |
| 연구 실행계획           | 과제·기관·자료별 실행 가능한 철회 조치·기한; 계획 없는 제공 보류                              |
| 공개 전환               | 최종 조문 번호·원문·별표·참고 번역·안내·개정 이력 동기화                                      |

위 항목은 정비 방향에 대한 동의를 받았다는 이유만으로 실제 운영이 마련되었다고
처리하지 않는다. 정관의 목적사업 등 별도 검토 대상도 이번 통합 규정으로 변경하지
않는다.
