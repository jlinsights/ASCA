# 作家·會員·理監事資格及要件

本說明將分散於章程及各項規定中之作家、會員、理監事資格與要件彙整於一處。內容有出入時，以[章程](#Articles-of-Incorporation)及[推薦·特邀作家選任規定](#Regulations-on-the-Appointment-of-Recommended-and-Invited-Artists)等各規定原文為準。

| 類別     | 資格                                                     | 年費     | 註冊費·發展基金         |
| -------- | -------------------------------------------------------- | -------- | ----------------------- |
| 青年作家 | 該年度1月1日基準年滿40歲以下，且認同協會理念與宗旨之作家 | 3萬韓元  | 首次加入時1萬韓元       |
| 一般作家 | 該年度1月1日基準年滿41歲以上，且認同協會理念與宗旨之作家 | 5萬韓元  | 首次加入時2萬韓元       |
| 推薦作家 | 依推薦·特邀作家選任規定選任為推薦作家者                  | 8萬韓元  | 晉升時3萬韓元           |
| 特邀作家 | 依推薦·特邀作家選任規定選任為特邀作家者                  | 10萬韓元 | 晉升時5萬韓元           |
| 理監事   | 特邀作家中符合活動標準，經理事會推薦並由會員大會選出者   | 20萬韓元 | 就任時發展基金200萬韓元 |

- 依據：會員及會費規定第2條第2項、第3條第1項·第2項、第4條。

## 作家

1. 作家分為青年作家、一般作家、推薦作家及特邀作家。青年作家與一般作家依該年度1月1日基準之年齡區分，推薦作家與特邀作家經審查後選任。
2. 自2024年起，推薦作家及特邀作家證書分為傳統部門與現代部門頒發（推薦·特邀作家選任規定第2條第3項）。
3. 非本會正式會員之作家，亦得參加特邀作家展（書境）之個展及攤位展。參展費適用會員及會費規定第7條之標準價（非會員），詳細事項依該年度徵件簡章辦理。

### 推薦作家與特邀作家之選任

1. 推薦作家自以正式會員身分活動3年以上並取得入賞分數10分以上者中選任；特邀作家自以推薦作家身分活動5年以上並取得入賞分數15分以上者中選任（選任規定第2條、第9條第2項）。
2. 除分數外，須同時具備下列要件（選任規定第3條）：最近3年內連續參展本會展覽、通過資格審查委員會之代表作作品集審查、對協會之貢獻活動3次以上、最近5年內未受懲戒處分。
3. 審查每年辦理2次，分為書面審查與作品審查（最近3年內創作之代表作3件），經評審委員三分之二以上同意授予資格，由理事長最終選任（選任規定第8條）。
4. 對書法文化發展有特殊貢獻者、從事國內外書法教育20年以上者、於文化體育觀光部登記之其他書法團體之特邀作家，得經理事會三分之二以上同意決議特別選任。須由本人申請（理事會推薦時須經本人同意），理事會僅就通過資格審查委員會書面·作品審查者作成決議。非正式會員者之申請書兼為入會申請書，並繳納會員及會費規定第3條第4項之特別選任註冊費（審查費·註冊費·首年年費合計：推薦作家18萬韓元、特邀作家25萬韓元）。正式會員繳納各階段晉升註冊費，資格停止之會員應先繳清未繳年費後始得申請（選任規定第11條）。
5. 維持特邀作家資格30年以上者，或年滿70歲以上且對協會發展有顯著貢獻者，得推舉為名譽作家，名譽作家免除會費及參展義務（選任規定第12條）。

### 推薦作家與特邀作家之資格維持

1. 推薦作家及特邀作家負有每2年為資格更新提交作品、每年參加協會主辦展覽1次以上、參與新進作家指導及輔導、繳納年費之義務（選任規定第9條第1項）。
2. 連續2年未參加展覽，或年費未繳納達2年以上者，停止其資格（選任規定第10條第1項）。
3. 嚴重損害協會名譽、資格停止期間逾3年、本人以書面申請放棄資格，或遭除名者，撤銷其資格（選任規定第10條第2項）。

## 會員

1. 認同本會設立宗旨，提出入會申請書並經理事會同意者，成為會員（章程第5條）。
2. 會員為現正從事傳統韓文及漢文書法、現代書法、Calligraphy、書刻、篆刻及文人畫、水墨畫（梅、蘭、菊、竹）、民畫等之作品活動、教育及研究者，或有意願以個人才能貢獻於地區或個人等志願服務活動者，並已完成規定之入會程序及繳納年費者。
3. 會員分為每年繳納年費之一般會員，及繳納終身會費而永久免除年費繳納義務之終身會員（會員及會費規定第2條第1項）。
4. 正式會員為繳納年費或終身會費之青年、一般、推薦、特邀作家及理監事。資格停止之會員及章程第6條之準會員、特別會員、名譽會員，不屬於正式會員（會員及會費規定第2條第3項）。
5. 特邀作家以上之正式會員，得繳納相當於年費10倍之終身會費成為終身會員，此後永久免除年費繳納義務（會員及會費規定第3條第3項）。
6. 準會員、特別會員、名譽會員得出席會員大會並發言，但無表決權（章程第6條）。
7. 會員得向理事長提出退會申請書而自由退會（章程第8條）。

## 理監事

1. 理監事為特邀作家中，滿足理監事所要求之另行活動標準（例如：過去3年間參與協會主要活動5次以上、參與特定委員會活動等），經理事會推薦並由會員大會選出者（會員及會費規定第2條第2項、章程第11條）。
2. 就任理監事之會員應繳納發展基金200萬韓元，得透過CMS分期繳納，最長20個月。繳清後自動取得終身會員資格；已為終身會員者，繳納扣除已繳終身會費後之差額（會員及會費規定第3條第3項、第4條）。
3. 理事中具有民法第777條所定親屬關係者，不得超過理事名額之五分之一；監事相互間或與理事間不得具有親屬關係（章程第13條）。
4. 違反本會宗旨、理監事間發生糾紛、會計舞弊或顯著不當行為，或妨礙本會業務之理監事，得經會員大會決議解任（章程第12條）。

## 會費繳納與資格管理

1. 年費原則上應於每年1月31日前繳納（會員及會費規定第5條第1項）。
2. 未繳納當年度年費者，限制其會員活動所需之權限；連續2年未繳納者，停止其會員資格；連續3年未繳納者，得依章程第9條經理事會決議由理事長除名。繳清未繳年費後恢復原有資格，遭除名之會員須重新入會（會員及會費規定第5條）。
3. 註冊費與年費之繳納，透過[線上募款專區](https://secure.donus.org/orientalcalligraphy/pay)辦理，並可透過[個人頁面](https://secure.donus.org/orientalcalligraphy/mypage)確認會員或理監事本人之繳納明細。

## 權利與義務

1. 本會之正式會員，對本會推動之國內外展覽等事業及理監事，享有選舉權與被選舉權，並有權出席會議、提出有關本會活動之意見，及參與表決。
2. 會員得免費取得本會之資料及出版品。但展覽圖錄依會員及會費規定第9條辦理（參展之正式會員免費取得1冊，其餘額外購買者付費）。
3. 本會之會員與理監事，須必定繳納規定之入會及註冊費與年費，並有遵守會員大會決議之一切事項之義務。
4. 本會之會員與理監事，有出品本會主辦之展覽、參加各項活動，並遵守章程及相關規則等一切規定之義務。
5. 對本會發展有貢獻之會員得予褒獎；違反本會宗旨、損害本會名譽或不履行會員義務者，得予除名、譴責等懲戒（章程第9條）。
6. 對於已繳納年費之所有正式會員，及繳納協會指定金額以上之發展基金、贊助金及捐款之理監事，提供可持續管理及展示本人經歷與作品之網路空間，並刊登於東洋書藝協會網站。
