# 會員·理監事資格及要件

| 會員類別 | 年費     | 備註                     |
| -------- | -------- | ------------------------ |
| 青年作家 | 3萬韓元  | 首次加入時註冊費1萬韓元  |
| 一般作家 | 5萬韓元  | 首次加入時註冊費2萬韓元  |
| 推薦作家 | 8萬韓元  | 晉升時註冊費3萬韓元      |
| 特邀作家 | 10萬韓元 | 晉升時註冊費5萬韓元      |
| 理監事   | 20萬韓元 | 就任理監事時繳納發展基金 |

- 年費繳納截止日原則上為每年1月底。
- 理監事就任時之發展基金，得按月定期分期繳納。
- 青年作家為該年度1月1日基準年滿40歲以下、一般作家為同一基準年滿41歲以上之作家，且認同協會之理念與宗旨者。
- 推薦作家須以正式會員身分活動3年以上，並取得入賞分數10分以上；特邀作家須以推薦作家身分活動5年以上，並取得入賞分數15分以上，二者均依⟪推薦·特邀作家選任規定⟫之基準與程序選任。
- 理監事為特邀作家中，滿足理監事所要求之另行活動標準（例如：過去3年間參與協會主要活動5次以上、參與特定委員會活動等），並依章程第11條經理事會推薦、由會員大會選出者。
- 正式會員為繳納年費或終身會費之青年、一般、推薦、特邀作家及理監事（會員及會費規定第2條第3項）。

### **會員與理監事之資格**

1. 本會之會員與理監事，為現正從事傳統韓文及漢文書法、現代書法、Calligraphy、書刻、篆刻、文人畫、水墨畫（梅、蘭、菊、竹）、民畫等之作品活動、教育及研究者，或有意願為研發而以個人才能貢獻於地區或個人等志願服務活動者。
2. 認同社團法人 東洋書藝協會之設立宗旨，完成規定之入會程序並繳納年費者。
3. 其他推薦作家及特邀作家、理監事等之資格，依「[章程](#Articles-of-Incorporation)」及「[推薦·特邀作家選任規定](#Regulations-on-the-Appointment-of-Recommended-and-Invited-Artists)」辦理。
4. 推薦作家須具備3年以上之正式會員經歷及入賞實績；特邀作家須具備5年以上之推薦作家經歷。

### **會員與理監事之權利與義務**

1. 本會之正式會員，對本會推動之國內外展覽等事業及理監事，享有選舉權與被選舉權，並有權出席會議、提出有關本會活動之意見，及參與表決。
2. 會員得免費取得本會之資料及出版品。但展覽圖錄依會員及會費規定第9條辦理（參展之正式會員免費取得1冊，其餘額外購買者付費）。
3. 本會之會員與理監事，須必定繳納規定之入會及註冊費與年費，並有遵守會員大會決議之一切事項之義務。
4. 本會之會員與理監事，有出品本會主辦之展覽、參加各項活動，並遵守章程及相關規則等一切規定之義務。
5. 依章程第7條第3款，會員未繳納會費及各項負擔金時之權限限制、資格停止與恢復，依會員及會費規定第5條辦理。
6. 註冊費與年費之繳納，透過[線上募款專區](https://secure.donus.org/orientalcalligraphy/pay)辦理，並可透過[個人頁面](https://secure.donus.org/orientalcalligraphy/mypage)確認會員或理監事本人之繳納明細。
7. 所有繳納年費之正式會員，以及繳納協會所指定金額以上之發展基金、贊助金及捐款之理監事，本會將提供可持續管理及展示個人經歷與作品之網路空間，並刊載於東洋書藝協會網站。
