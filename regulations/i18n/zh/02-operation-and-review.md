# 運營及審查規定

> [施行 2025. 2. 8.] [第3號施行令，2026. 1. 1.，部分修正]

### 第1條（目的）

本規定依章程第41條，為規定社團法人 東洋書藝協會（以下稱「本會」）運營委員及評審委員之委任、審查方法等展覽運營全般相關事項，特訂定之。

### 第2條（組成與任務）

① 運營委員由運營委員長與運營委員組成，並應為大韓民國 東洋書藝大展之順利運營而盡力。

② 評審委員由評審委員長與評審委員組成，透過大韓民國 東洋書藝大展之公正審查，選定入賞作品。

### 第3條（資格）

本會運營委員及評審委員之資格如下各項。

① 本會特邀作家（含諮詢委員、顧問）

② 其他書法團體之特邀作家

③ 本會顧問或諮詢委員推薦之人士

### 第3條之2（評審委員之迴避：法定迴避、自行迴避、聲請迴避）

① 評審委員有下列各款情形之一者，應於該作品之審查中被法定迴避（除斥）。

1. 評審委員為出品人之配偶或直系尊卑屬者
2. 評審委員為出品人之老師，或出品人為評審委員之學生者（例：大學、研究所之指導教授等）
3. 其他有明顯事由，致難以期待公正審查者

② 評審委員具有前項事由，或自認難以公正審查時，經評審委員長許可，得自行迴避該作品之審查。

③ 出品人如認評審委員具有第1項事由，得於審查開始前以書面聲請迴避（忌避），由評審委員長決定之。

### 第3條之3（招募委員之資格）

本會招募委員之資格如下各項，並以對協會展覽之理解及宣傳活動之積極性為最優先考量。

1. 本會正式會員，活動期間滿1年以上且積極參與協會活動者
2. 於美術或藝術相關領域具3年以上宣傳、行銷或企劃工作經歷者
3. 獲本會特邀作家1人以上推薦，且經認定有明確意願為協會發展作出貢獻者
4. 曾於本會主辦之公募展或展覽中出品3次以上者

### 第4條（委任方法）

理事長應於大韓民國 東洋書藝大展舉辦1個月前，依審查件數決定人數，並推薦其兩倍人數，經理事會決議後決定委任，並頒發委任證書。

### 第4條之2（委員津貼及報酬）

① 委員之報酬依活動性質，區分為津貼及差旅費、績效獎勵發放。本委員為委任職，並非勞動關係，報酬依協會財務狀況及內部規定訂定。

② 評審委員報酬依下列各款發放。

| 類別               | 訂定基準（每人提議金額）    | 發放原則                   |
| ------------------ | --------------------------- | -------------------------- |
| 審查津貼（審查費） | 15萬韓元（1日／半日）       | 依審查規模及所需時間發放   |
| 稿費（審查評語）   | 10萬韓元（每件）            | 撰寫審查評語時另行發放     |
| 旅費（交通費）     | 實支實報（KTX、高速巴士等） | 實支實報發放               |
| 餐費（午餐／晚餐） | 2萬韓元（每餐）             | 審查日程含午餐或晚餐時發放 |

③ 運營委員報酬依下列各款發放。

| 類別           | 訂定基準（每人提議金額） | 發放原則                        |
| -------------- | ------------------------ | ------------------------------- |
| 會議出席津貼   | 10萬韓元（每次）         | 依會議時間（以2小時為基準）發放 |
| 旅費（交通費） | 實支實報（原則）         | 準用評審委員之基準              |
| 餐費（必要時） | 2萬韓元（每餐）          | 依會議時間發放                  |

④ 招募委員之績效獎勵依募集實績，按下表各區間發放，並與招募委員之會議出席等基本活動津貼分別合計發放。募集人數達30名時，第1名至第30名以每人10,000韓元計算，自第31名起加計該區間之單價。

| 類別           | 募集人數（名） | 發放基準                     | 發放金額（累計）  |
| -------------- | -------------- | ---------------------------- | ----------------- |
| Tier 4（深化） | 1~29名         | 每人5,000韓元                | 人數 × 5,000韓元  |
| Tier 3（熟練） | 30名           | 第1~30名每人10,000韓元       | 300,000韓元       |
| Tier 2（優秀） | 31~40名        | 第31~40名每人加計12,000韓元  | 40名時420,000韓元 |
| Tier 1（最上） | 41名以上       | 自第41名起每人加計15,000韓元 | 50名時570,000韓元 |

⑤ 運營委員、評審委員、招募委員等兼任職務時，若活動日期及職務性質不同，原則上合計發放各項津貼。但**評審委員兼任募集活動時**，若其所募集之出品人列為該公募展之審查對象，**該評審委員應排除於募集績效獎勵之發放對象，或必須於該出品作品之審查中予以法定迴避**。

### 第5條（審查部門及規格）

大韓民國 東洋書藝大展之公募作品規格為**國展紙（70×200cm）、全開（70×136cm）、半開（35×136cm）**，公募部門分為下列5個部門；必要時得經理事會決議增設審查部門。

① 韓文（韓文正書、正書混用、韓文半草、半草混用、韓文真草、板本體、民體等）

② 漢文（甲骨、金文、篆書、隸書、楷書、行書、草書）

③ 現代書法·Calligraphy（含現代韓國畫）

④ 篆刻·書刻（含木刻、石刻）

⑤ 文人畫、東洋畫、設色畫、水墨畫、民畫

### 第6條（審查）

① 以古法帖為準選定作品，著重於各書體之構成、留白、調和、墨色，決定作品藝術性之優劣。

② 審查點劃、結構、章法、調和之完成美，並比較下表之各項要素。

|      |      |      |      |
| ---- | ---- | ---- | ---- |
| 點劃 | 結構 | 章法 | 調和 |
| 方圓 | 大小 | 濃淡 | 氣韻 |
| 曲直 | 疏密 | 剛柔 | 雅俗 |
| 輕重 | 虛實 | 緩急 | 美醜 |
| 藏露 | 向背 | 餘白 | 通變 |
| 形質 | 呼應 | 構成 | 創新 |

③ 審查計畫及準備

甲. 評審委員長應於審查開始前製作[別表1]審查計畫書，並載明下列事項：

1. 審查日程及進行方式
2. 各部門之評審委員組成
3. 評分標準之細部適用方式
4. 作品陳列及檢討方式

乙. 對收件作品給予審查編號，並將作者資訊加以封存，以保障匿名性。

丙. 評審委員長應於審查前，就評分標準實施事前教育。

④ 審查進行及評分方式

甲. 各評審委員應使用[別表2]審查表，各項目配分如下：

1. 點劃：25分（評分要素：方圓、曲直、輕重、藏露、形質等）
2. 結構：25分（評分要素：大小、疏密、虛實、向背、呼應等）
3. 章法：25分（評分要素：濃淡、剛柔、緩急、餘白、構成等）
4. 調和：25分（評分要素：氣韻、雅俗、美醜、通變、創新等）

乙. 評分以5分為單位，並簡要記載各項目之評分依據。

丙. 計算各評審委員之總分，並以去除最高分與最低分後之平均分數作為最終分數。

⑤ 審查意見撰寫

甲. 審查完成後，各評審委員應撰寫[別表3]審查意見書：

1. 韓文部門審查評語
2. 漢文部門審查評語
3. 現代書法·Calligraphy部門審查評語
4. 篆刻·書刻部門審查評語
5. 文人畫、東洋畫、設色畫、水墨畫、民畫部門審查評語
6. 總體審查評語及改進建議

乙. [別表3]審查意見書應包括出品作品之整體水準、特徵性傾向、優秀作品之特性等。

⑥ 綜合評價及結果彙整

甲. 評審委員長應彙整[別表4]審查結果綜合表，並整理下列事項：

1. 各作品之評審委員評分
2. 最終平均分數之算出
3. 排名及等級之決定

乙. 等級決定基準：

1. 90分以上：大獎及最優秀獎候選
2. 85分以上：優秀獎候選
3. 80分以上：特選候選
4. 75分以上：入選候選

丙. 同分時之處理方案：

1. 調和分數較高之作品優先
2. 章法分數較高之作品優先
3. 經評審委員間協商決定

丁. 大獎選定：獲得90分以上之作品為2件以上時，經評審委員全體投票決定最終大獎。

⑦ 審查結果確定

甲. 評審委員長應將綜合審查結果報告理事長。

乙. 理事會應審閱審查結果並予以最終核准。

丙. 確定之審查結果應個別通知得獎者，並公布於協會網站。

丁. 評審委員對特選以上得獎作品（正獎、特別獎、特選），應撰寫約50字之「審查評語（Key-point
Feedback）」，協會並提供系統，供作家線上查詢本人之審查評分表及審查評語。

### 第7條（獎項內容及獎金）

① 依第6條審查結果選定之入賞作品，依下列方式頒獎。

② 依第6條審查結果之入賞等級，區分為**正獎、特別獎、特選及入選**。

③ 各入賞等級之細部內容、選定人數及獎金如下。

**甲. 正獎（以作品之藝術性為最優先基準選定）**

- 大獎：1名，獎狀及獎金200萬韓元
- 最優秀獎：1名，獎狀及獎金100萬韓元
- 優秀獎：2名，獎狀及獎金30萬韓元

**乙. 特別獎（鼓勵書法之均衡研究及多體出品）**

- 五體獎：3名，獎狀及獎金20萬韓元
- 三體獎：4名，獎狀及獎金15萬韓元

**丙. 其他入賞**

- 特選：30名（可調整），獎狀
- 入選：50名（可調整），獎狀

④ 第3項之特別獎，係反映協會鼓勵作家對多種字體進行多角度之努力與研究之營運方針而訂定。

⑤ 第3項所載之獲獎人數（含特選、入選），得經理事會決議，依當年度出品作品之總數及作品之整體水準予以調整。

⑥ 除第3項外，若協會財務狀況良好或取得特別贊助，得經理事會決議，另行增設特別獎（例：贊助企業獎、理事長獎等）予以頒獎。

⑦ 獎金所課徵之各項稅捐，原則上由得獎者本人負擔。

⑧ 頒獎典禮及獎金發放之詳細程序，由理事長另行訂定並公告。

### 第8條（任期）

**運營委員及評審委員之任期，自委任日起至當年度大韓民國 東洋書藝大展結束之日為止。**
但依異議提出處理規定所受理之異議，其重新審驗業務，應執行至該處理完成為止。

### 第9條（會員大會議案之事前公開及意見徵集）

① 理事會應於會員大會召開7日前，透過協會網站及線上管道，將擬提交會員大會之主要議案，向**全體會員（含準會員）**公開。

② 協會提供線上留言或電子問卷功能，使所有會員無論其等級為何，均得就議案提出意見。

③ 理事會應於會員大會中，強制報告經由第2項所徵集之會員主要意見。
