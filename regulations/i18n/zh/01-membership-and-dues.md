# 會員及會費規定

> [施行 2026. 1. 1.]

### 第1條（目的）

本規定為明確規定東洋書藝協會（以下稱「協會」）之會員資格、會費體系及繳納程序等，以確保協會之健全財務運營及會員間之公平，並為東洋書藝文化之發展作出貢獻為目的。

### 第2條（會員之種類及定義）

① **（會員之區分）**
協會之會員依繳納義務，區分為下列「一般會員」與「終身會員」。

**甲. 一般會員**：加入協會，並每年繳納本規定第3條所定年費之會員

**乙. 終身會員**：加入協會，並一次（或分期）繳納本規定**第3條第3項或第4條**所定終身會費，而永久免除年費繳納義務之會員

② **（會員之等級）**
第1項之會員依協會之活動經歷及成果，授予下列等級，各等級之權利與義務另由理事會訂定。

甲.
"**青年作家**"：於該年度1月1日之基準，年滿**40歲以下**之作家，且認同協會之理念與宗旨者

乙.
"**一般作家**"：於該年度1月1日之基準，年滿**41歲以上**之作家，且認同協會之理念與宗旨者

丙. "**推薦作家**"：依⟪推薦·特邀作家選任規定⟫選任為推薦作家者

丁. "**特邀作家**"：依⟪推薦·特邀作家選任規定⟫選任為特邀作家者

戊.
"**理監事**"：特邀作家中，滿足理監事所要求之另行活動標準（例如：過去3年間參與協會主要活動5次以上、參與特定委員會活動等），並經理事會推薦，依章程第11條由會員大會選出者

③ **（正式會員）**
本規定及其他規定所稱「正式會員」，指依第3條繳納年費或終身會費之青年作家、一般作家、推薦作家、特邀作家及理監事。依第5條資格被停止之會員，以及章程第6條之準會員、特別會員、名譽會員，不包括於正式會員之內。

### 第3條（會費及註冊費基準）

**① 年費**

| 類別     | 年費     | 備註               |
| -------- | -------- | ------------------ |
| 青年作家 | 3萬韓元  | 加入時另繳註冊費   |
| 一般作家 | 5萬韓元  | 加入時另繳註冊費   |
| 推薦作家 | 8萬韓元  | 晉升時另繳註冊費   |
| 特邀作家 | 10萬韓元 | 晉升時另繳註冊費   |
| 理監事   | 20萬韓元 | 就任時繳納發展基金 |

**② 註冊費（加入及晉升審查時）**

| 類別     | 註冊費  | 備註                       |
| -------- | ------- | -------------------------- |
| 青年作家 | 1萬韓元 | 首次加入時一次繳納         |
| 一般作家 | 2萬韓元 | 首次加入時一次繳納         |
| 推薦作家 | 3萬韓元 | 由青年、一般作家晉升時繳納 |
| 特邀作家 | 5萬韓元 | 由推薦作家晉升時繳納       |

**③ 終身會員**

**甲. （資格）** 特邀作家以上之正式會員，均得繳納終身會費並申請終身會員資格。

**乙. （會費）** 終身會費以年費（第3條第1項）之10倍金額訂定。

**丙. （理監事特例）**
依第4條繳納發展基金200萬韓元之理監事，視為已完成終身會費之繳納，自動取得終身會員資格。

**丁. （福利及資格維持）**
已完成終身會費繳納之會員，不論其後是否就任理監事，均永久維持「終身會員」資格，且其後永久免除年費（第3條第1項）之繳納義務。

**戊. （就任理監事時之義務）**
終身會員就任理監事時之發展基金，依第4條第4項辦理。

**④ 特別選任註冊費（推薦·特邀作家選任規定第11條）**

| 類別     | 審查費（申請時） | 註冊費（選任決議後） | 首年年費（選任決議後） | 合計     |
| -------- | ---------------- | -------------------- | ---------------------- | -------- |
| 推薦作家 | 5萬韓元          | 5萬韓元              | 8萬韓元                | 18萬韓元 |
| 特邀作家 | 5萬韓元          | 10萬韓元             | 10萬韓元               | 25萬韓元 |

※ 適用於非本會正式會員者經特別選任之情形。註冊費為正式會員取得相同資格所繳納之入會·晉升註冊費（第2項）之合計，首年年費為第1項該等級之年費。註冊費與首年年費以理事會決議之資格為準，減免依推薦·特邀作家選任規定第11條第7項辦理。

### 第4條（理監事發展基金及福利）

① 就任理監事之會員，為協會之發展，應繳納**發展基金200萬韓元**。

② 發展基金得透過CMS最多分20個月繳納。

③ 依第1項完成繳納發展基金200萬韓元之正式會員，**自動取得「終身會員」資格，其後永久免除年費繳納義務。**

④ 依第3條第3項已取得終身會員資格之會員獲聘為理監事時，應繳納第1項之發展基金200萬韓元，扣除**既已繳納之終身會費**後之差額。

### 第5條（會費繳納期間及資格管理）

① 年費原則上應於每年1月31日前繳納。

② 年費未繳之處置

**甲. 第1次未繳（當年度年費未繳時）：**
通知未繳事實後，限制會員活動所需之權限（例如：

網頁存取、參與特定活動等）。

**乙. 第2次未繳（連續2年未繳時）：** 會員資格停止，所有會員福利及權限中止。

**丙. 第3次未繳（連續3年未繳時）：**
依章程第9條，經理事會決議後，由理事長得予以開除。

③ 權限受限制或資格被停止之會員，若補繳未繳年費，原有資格即予恢復。被開除之會員，依章程第5條須重新入會。

④ 因特殊事由，經理事會核准，得延期繳納或分期繳納。

### 第8條（裝裱費規定）

① 對入選以上之作品課徵裝裱費，裝裱以**協會所定之標準選項及價格**進行。

② 協會所提供之裝裱服務，原則上堅持採用**手工背襯**方式，而非機械背襯。

③ 裝裱費以**實際裝裱成本為基礎**訂定，並對會員提供折扣優惠。

④ 依作品規格之裝裱費如下。

| 作品規格           | 標準價（適用於非會員） | 會員價（適用於正式會員） |
| ------------------ | ---------------------- | ------------------------ |
| 半開（35x135cm）   | 每件8萬韓元            | 每件6萬韓元              |
| 全開（70x135cm）   | 每件10萬韓元           | 每件8萬韓元              |
| 國展紙（70x200cm） | 每件12萬韓元           | 每件10萬韓元             |

### 第9條（圖錄費規定）

1. 參展之正式會員，免費提供圖錄1冊。
2. 額外購買，或非參展之正式會員：

| 類別   | 圖錄額外購買（每冊） |

| 非會員 | 3萬韓元              |

### 第10條（作家個人網站初期建置費及年度維護費規定）

① 與協會簽訂網站製作及維護合約，並**繳納年度維護費之正式會員**，該年度之年費免除。

② 於展覽中出品40件以上作品之作家，享有下列優惠。

**甲. （首次優惠）**
全額免除個人網站製作費及第1年度之維護費，並免除該年度之年費。

**乙. （持續優惠）**
自第2年度起，**僅需繳納年度維護費**，即可持續獲得網站維護服務，**該年度之年費免除**。

③ 於展覽中出品30件以上作品之作家，免除初期建置費，並免除該年度之年費。

④ 於展覽中出品20件以上作品之作家，初期建置費折扣50%。

| 非會員 | 初期建置費700,000韓元 / 年度維護費300,000韓元 |

### 第11條（繳納方法）

① 所有費用原則上以線上方式繳納（帳戶轉帳、CMS扣款等）。

② 透過線上付款系統繳納，買受人如有需要，應可開立電子收據。

### 第12條（正式會員基本福利）

**① 正式會員共同福利**

甲. 參加展覽時，免費提供圖錄1冊

乙. 參展費、裝裱費及圖錄費適用優惠價

丙. 建置作家個人網站時，免除年費

**② 推薦作家以上之額外福利**

甲. 獲得特邀作家候選登錄之機會

乙. 優先參加特別展覽及海外交流展之權利

丙. 符合要件者，獲選個人網站初期建置費之部分補助

**③ 特邀作家以上之額外福利**

甲. 理監事候選人推薦資格（依章程第11條，由會員大會選出）

乙. 運營委員及評審委員資格（運營及審查規定第3條）

**④ 理監事福利**

甲. 優先受聘為運營委員及評審委員

乙. 作家個人網站初期建置費及年度維護費減免1年

丙. 特邀作家展參展費（依該展覽徵件簡章所定金額）折扣5%

### 第13條（高齡會員福利）

滿70歲以上、加入期間滿10年以上之會員中，對協會發展之功績，經依下列各款標準認定為顯著者，得經理事會審議後，給予年費減免之福利。

① 參與協會主要展覽5次以上

② 協會主辦之研討會及工作坊擔任講師3次以上

③ 於協會事業之規劃與執行上扮演核心角色等

此時，功績審議應依另行訂定之「功績審查標準」客觀進行，必要時得組成「功績審查小委員會」進行評估。

### 第14條（分會活動補助金）

① 協會應於每年預算範圍內，編列「分會活動補助金」，以促進分會及支會之活化。

② 分會主辦之地區公募展及企畫展，經本會理事會核准後，得使用「協會贊助名稱」，本會並應就此提供所需之宣傳及評審委員派遣之支援。

③ 對表現優良之分會，於年終會員大會予以表揚，並得於次年度增加補助金。

## 附則 <2026. 1. 1.>

### 第1條（施行日）

本規定經理事會決議公布之日起施行。

### 第2條（準用規定）

本規定未明定之事項，依理事會之決議辦理。

### 第3條（修正）

本規定依章程第41條，經理事會決議修正，修正內容應於次屆會員大會報告。
