# 作家・会員・役員の資格及び要件

この案内は、定款と各規程に分散している作家・会員・役員の資格及び要件を一か所にまとめたものである。内容が異なる場合は、[定款](#Articles-of-Incorporation)及び[推薦・招待作家選任規程](#Regulations-on-the-Appointment-of-Recommended-and-Invited-Artists)等、各規程の原文が優先する。

| 区分     | 資格                                                                       | 年会費     | 登録費・発展基金            |
| -------- | -------------------------------------------------------------------------- | ---------- | --------------------------- |
| 青年作家 | 当該年の1月1日基準で満40歳以下の作家であって、協会の理念と目的に賛同する者 | 3万ウォン  | 最初の加入時に1万ウォン     |
| 一般作家 | 当該年の1月1日基準で満41歳以上の作家であって、協会の理念と目的に賛同する者 | 5万ウォン  | 最初の加入時に2万ウォン     |
| 推薦作家 | 推薦・招待作家選任規程に従い推薦作家に選任された者                         | 8万ウォン  | 昇格時に3万ウォン           |
| 招待作家 | 推薦・招待作家選任規程に従い招待作家に選任された者                         | 10万ウォン | 昇格時に5万ウォン           |
| 役員     | 招待作家のうち活動基準を満たし、理事会の推薦を受けて総会で選出された者     | 20万ウォン | 就任時に発展基金200万ウォン |

- 根拠：会員及び会費規程第2条第2項、第3条第1項・第2項、第4条。

## 作家

1. 作家は、青年作家・一般作家・推薦作家・招待作家に区分する。青年作家と一般作家は当該年の1月1日基準の年齢で定め、推薦作家と招待作家は審査を経て選任する。
2. 2024年から、推薦作家及び招待作家の証書は伝統部門と現代部門に分けて授与する（推薦・招待作家選任規程第2条第3項）。
3. 協会の正会員でない作家も、招待作家展（書境）の個展・ブース展に参加することができる。出品料には会員及び会費規程第7条の標準価格（非会員）を適用し、詳細は当該年の募集要項に従う。

### 推薦作家と招待作家の選任

1. 推薦作家は、正会員として3年以上活動し入賞点数10点以上を取得した者の中から、招待作家は、推薦作家として5年以上活動し入賞点数15点以上を取得した者の中から選任する（選任規程第2条、第9条第2項）。
2. 点数とは別に、次の要件をすべて満たさなければならない（選任規程第3条）：直近3年以内の本会展示への連続出品、資格審査委員会による代表作ポートフォリオ審査の通過、協会への貢献活動3回以上、直近5年以内に懲戒処分を受けた事実がないこと。
3. 審査は年2回、書類審査と作品審査（直近3年以内に制作した代表作3点）により行い、審査委員の3分の2以上の賛成で資格を付与し、理事長が最終的に選任する（選任規程第8条）。
4. 書道文化の発展に特別な貢献のある者、国内外の書道教育に20年以上従事した者、文化体育観光部に登録された他の書道団体の招待作家は、理事会の3分の2以上の賛成議決により特別選任することができる（選任規程第11条）。
5. 30年以上招待作家の資格を維持した者、又は満70歳以上であって協会の発展に顕著な貢献のある者は、名誉作家に推戴することができ、名誉作家は会費及び出品の義務を免除する（選任規程第12条）。

### 推薦作家と招待作家の資格維持

1. 推薦作家及び招待作家は、2年ごとの資格更新のための作品提出、年1回以上の協会主催展示会への参加、新進作家の指導及びメンタリングへの参加、年会費の納付の義務を負う（選任規程第9条第1項）。
2. 2年連続で展示会に参加しない場合、又は年会費を2年以上未納した場合は、資格を停止する（選任規程第10条第1項）。
3. 協会の名誉を著しく毀損した場合、資格停止期間が3年を超えた場合、本人が書面で資格の放棄を申請した場合、除名された場合は、資格を取り消す（選任規程第10条第2項）。

## 会員

1. 本会の設立趣旨に賛同し、入会申請書を提出して理事会の承認を得た者が会員となる（定款第5条）。
2. 会員は、伝統的なハングル及び漢字書道、現代書道、カリグラフィー、書刻、篆刻及び文人画、水墨画（梅・蘭・菊・竹）、民画等の作品活動、教育又は研究を行っている者、あるいは才能を地域や個人に分かち合う奉仕活動に関心の高い者であって、所定の加入手続を終えて年会費を納付した者である。
3. 会員は、年会費を毎年納付する一般会員と、終身会費を納付して年会費の納付義務を永久に免除された終身会員に区分する（会員及び会費規程第2条第1項）。
4. 正会員は、年会費又は終身会費を納付した青年・一般・推薦・招待作家及び役員である。資格を停止された会員と定款第6条の準会員・特別会員・名誉会員は、正会員に含まない（会員及び会費規程第2条第3項）。
5. 招待作家以上の正会員は、年会費の10倍に当たる終身会費を納付して終身会員となることができ、以後、年会費の納付義務を永久に免除される（会員及び会費規程第3条第3項）。
6. 準会員・特別会員・名誉会員は、総会に出席して発言することができるが、議決権はない（定款第6条）。
7. 会員は、理事長に脱退届を提出して自由に脱退することができる（定款第8条）。

## 役員

1. 役員は、招待作家のうち役員として要求される別途の活動基準（例：過去3年間に協会の主要行事へ5回以上参加、特定の委員会活動等）を満たし、理事会の推薦を受けて総会で選出された者である（会員及び会費規程第2条第2項、定款第11条）。
2. 役員に就任する会員は発展基金200万ウォンを納付し、最大20か月までCMSにより分割納付することができる。完納すると終身会員の資格を自動的に取得し、既に終身会員である場合は、納付済みの終身会費を控除した差額を納付する（会員及び会費規程第3条第3項、第4条）。
3. 理事のうち民法第777条の親族関係にある者は理事定数の5分の1を超えることができず、監事は、監事相互間又は理事と親族関係にあってはならない（定款第13条）。
4. 本会の目的に反する行為、役員間の紛争・会計不正又は著しい不当行為、本会の業務を妨害する行為をした役員は、総会の議決を経て解任することができる（定款第12条）。

## 会費の納付と資格管理

1. 年会費は、毎年1月31日までに納付することを原則とする（会員及び会費規程第5条第1項）。
2. 当該年の年会費を未納すると会員活動に必要な権限が制限され、2年連続で未納すると会員資格が停止され、3年連続で未納すると定款第9条に従い理事会の議決を経て理事長が除名することができる。未納の年会費を完納すると従前の資格が復元され、除名された会員は改めて入会しなければならない（会員及び会費規程第5条）。
3. 登録費及び年会費の納付は、[オンライン募金窓口](https://secure.donus.org/orientalcalligraphy/pay)を通じて行い、[マイページ](https://secure.donus.org/orientalcalligraphy/mypage)を通じて会員又は役員本人の納付履歴を確認する。

## 権利と義務

1. 本会の正会員は、本会が推進する国内外の展示会等の事業及び役員に対する選挙権と被選挙権を有し、会議に出席して本会の活動に関する意見を提案し、議決に参加する権利を有する。
2. 会員は、本会の資料及び出版物を無償で提供を受けることができる。ただし、展示会の図録は会員及び会費規程第9条に従う（展示に参加した正会員は1冊無料、追加分は有料）。
3. 本会の会員及び役員は、所定の入会・登録費及び年会費を必ず納付しなければならず、総会で議決した諸事項を遵守する義務を有する。
4. 本会の会員及び役員は、本会が主催する展示会への出品、各種行事への出席、並びに定款及び関連規則等の諸規程を遵守する義務を有する。
5. 本会の会員として本会の発展に寄与した者は褒賞し、本会の目的に反し、又は名誉を損なう行為をし、若しくは会員の義務を履行しない者は、除名・譴責等の懲戒をすることができる（定款第9条）。
6. 年会費を納付したすべての正会員と、協会が指定した金額以上の発展基金、後援金及び寄付金を納付した役員には、本人の経歴と作品を継続的に管理及び展示することのできるサイバー空間を提供し、東洋書芸協会のホームページに掲載する。
