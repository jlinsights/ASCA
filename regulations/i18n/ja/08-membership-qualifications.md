# 会員・役員の資格及び要件

| 会員区分 | 年会費     | 備考                          |
| -------- | ---------- | ----------------------------- |
| 青年作家 | 3万ウォン  | 最初の加入時に登録費1万ウォン |
| 一般作家 | 5万ウォン  | 最初の加入時に登録費2万ウォン |
| 推薦作家 | 8万ウォン  | 昇格時に登録費3万ウォン       |
| 招待作家 | 10万ウォン | 昇格時に登録費5万ウォン       |
| 役員     | 20万ウォン | 役員就任時に発展基金を納付    |

- 年会費の納付期限は、原則として毎年1月末までである。
- 役員就任時の発展基金は、月ごとの分割納付が可能である。
- 青年作家は、当該年の1月1日基準で満40歳以下、一般作家は同じ基準で満41歳以上の作家であって、協会の理念と目的に賛同する者である。
- 推薦作家は、正会員として3年以上活動し、入賞点数10点以上を取得した者の中から選任する。招待作家は、推薦作家として5年以上活動し、入賞点数15点以上を取得した者の中から選任する。詳しい基準及び手続は⟪推薦・招待作家選任規程⟫に従う。
- 役員は、招待作家のうち役員として要求される別途の活動基準（例：過去3年間に協会の主要行事へ5回以上参加、特定の委員会活動等）を満たし、理事会の推薦を受けて定款第11条に従い総会で選出された者である。
- 正会員は、年会費又は終身会費を納付した青年・一般・推薦・招待作家及び役員である（会員及び会費規程第2条第3項）。

### **会員と役員の資格**

1. 本会の会員及び役員は、現在、伝統的なハングル及び漢字書道、現代書道、カリグラフィー、書刻、篆刻、文人画、水墨画（梅・蘭・菊・竹）、民画等の作品活動、教育又は研究を行っている者、あるいは研究開発のために自身の才能を地域や個人に分かち合う奉仕活動に関心の高い者である。
2. 社団法人 東洋書芸協会の設立趣旨に同意し、所定の加入手続を終えて年会費を納付した者である。
3. その他の推薦作家及び招待作家、役員等の資格は、「[定款](#Articles-of-Incorporation)」及び「[推薦・招待作家選任規程](#Regulations-on-the-Appointment-of-Recommended-and-Invited-Artists)」に従う。
4. 推薦作家には3年以上の正会員としての経歴と受賞実績が、招待作家には5年以上の推薦作家としての経歴が必要である。

### **会員と役員の権利と義務**

1. 本会の正会員は、本会が推進する国内外の展示会等の事業及び役員に対する選挙権と被選挙権を有し、会議に出席して本会の活動に関する意見を提案し、議決に参加する権利を有する。
2. 会員は、本会の資料及び出版物を無償で提供を受けることができる。ただし、展示会の図録は会員及び会費規程第9条に従う（展示に参加した正会員は1冊無料、追加分は有料）。
3. 本会の会員及び役員は、所定の入会・登録費及び年会費を必ず納付しなければならず、総会で議決した諸事項を遵守する義務を有する。
4. 本会の会員及び役員は、本会が主催する展示会への出品、各種行事への出席、並びに定款及び関連規則等の諸規程を遵守する義務を有する。
5. 定款第7条第3号に従い、会員が会費及び諸負担金を未納した場合の権限制限、資格停止及び復元は、会員及び会費規程第5条に従う。
6. 登録費及び年会費の納付は、[オンライン募金窓口](https://secure.donus.org/orientalcalligraphy/pay)を通じて行い、[マイページ](https://secure.donus.org/orientalcalligraphy/mypage)を通じて会員又は役員本人の納付履歴を確認する。
7. 年会費を納付したすべての正会員と、協会が指定した金額以上の発展基金、後援金及び寄付金を納付した役員には、本人の経歴と作品を継続的に管理・展示できるサイバー空間を提供し、東洋書芸協会のホームページに掲載する。
