# 会員及び会費規程

> [施行 2026. 1. 1.]

### 第1条（目的）

本規程は、東洋書芸協会（以下「協会」という。）の会員資格、会費体系及び納付手続等を明確に定めることにより、協会の健全な財政運営と会員間の衡平を確保し、東洋書芸文化の発展に寄与することを目的とする。

### 第2条（会員の種類及び定義）

① **（会員の区分）**
協会の会員は、納付義務に応じて次のとおり「一般会員」と「終身会員」に区分する。

**ア. 一般会員**：協会に加入し、本規程第3条に定める年会費を毎年納付する会員

**イ. 終身会員**：協会に加入し、本規程**第3条第3項又は第4条**に定める終身会費を一括（又は分割）で納付して、年会費納付義務を永久に免除された会員

② **（会員の等級）**
前項の会員は、協会活動の経歴及び成果に応じて次のような等級を付与され、等級に応じた権利及び義務は理事会で別途定める。

ア. 「**青年作家**」：当該年の1月1日基準で**満40歳以下**の作家であって、協会の理念と目的に賛同する者

イ. 「**一般作家**」：当該年の1月1日基準で**満41歳以上**の作家であって、協会の理念と目的に賛同する者

ウ. 「**推薦作家**」：⟪推薦・招待作家選任規程⟫に従い推薦作家に選任された者

エ. 「**招待作家**」：⟪推薦・招待作家選任規程⟫に従い招待作家に選任された者

オ. 「**役員**」：招待作家のうち、**役員として要求される別途の活動基準（例：過去3年間に協会の主要行事へ5回以上参加、特定の委員会活動等）を充足**し、理事会の推薦を受けて定款第11条に従い総会で選出された者

③ **（正会員）**
本規程及び他の規程において「正会員」とは、第3条に従う年会費又は終身会費を納付した青年作家・一般作家・推薦作家・招待作家及び役員をいう。第5条により資格が停止された会員、及び定款第6条の準会員・特別会員・名誉会員は、正会員に含まない。

### 第3条（会費及び登録費の基準）

**① 年会費**

| 区分     | 年会費     | 備考                       |
| -------- | ---------- | -------------------------- |
| 青年作家 | 3万ウォン  | 加入時に登録費を別途納付   |
| 一般作家 | 5万ウォン  | 加入時に登録費を別途納付   |
| 推薦作家 | 8万ウォン  | 昇格時に登録費を別途納付   |
| 招待作家 | 10万ウォン | 昇格時に登録費を別途納付   |
| 役員     | 20万ウォン | 役員就任時に発展基金を納付 |

**② 登録費（加入及び昇格審査時）**

| 区分     | 登録費    | 備考                           |
| -------- | --------- | ------------------------------ |
| 青年作家 | 1万ウォン | 最初の加入時に1回納付          |
| 一般作家 | 2万ウォン | 最初の加入時に1回納付          |
| 推薦作家 | 3万ウォン | 青年・一般作家から昇格時に納付 |
| 招待作家 | 5万ウォン | 推薦作家から昇格時に納付       |

**③ 終身会員**

**ア. （資格）**
招待作家以上の正会員は、誰でも終身会費を納付し、終身会員資格を申請することができる。

**イ. （会費）** 終身会費は、年会費（第3条第1項）の10倍に相当する金額に定める。

**ウ. （役員特例）**
第4条に従い発展基金200万ウォンを納付した役員は、本条の終身会費を完納したものとみなし、自動的に終身会員の資格を付与する。

**エ. （特典及び資格の維持）**
終身会費を完納した会員は、以後役員就任の有無にかかわらず「終身会員」の資格を永久に維持し、以後「年会費」（第3条第1項）の納付義務を永久に免除される。

**オ. （役員就任時の義務）**
終身会員が役員として就任する場合の発展基金は、第4条第4項に従う。

### 第4条（役員の発展基金及び特典）

① 役員として就任する会員は、協会の発展のため**発展基金200万ウォン**を納付しなければならない。

② 発展基金は、最大20か月までCMSを通じて分割納付が可能である。

③ 第1項に従い発展基金200万ウォンを完納した正会員は、**「終身会員」の資格を自動的に取得し、以後年会費の納付義務を永久に免除される。**

④ 第3条第3項により既に終身会員の資格を取得した会員が役員に委嘱される場合は、第1項の発展基金200万ウォンから**既納の終身会費を控除した差額**を納付しなければならない。

### 第5条（会費納付期間及び資格管理）

① 年会費は、毎年1月31日までに納付することを原則とする。

② 年会費未納に伴う措置

**ア. 第1次未納（当該年度の年会費未納時）：**
未納の事実を通知した後、会員活動に必要な権限（例：ウェブページへのアクセス、特定行事への参加等）が制限される。

**イ. 第2次未納（連続2年未納時）：**
会員資格が停止され、すべての会員特典及び権限が中断される。

**ウ. 第3次未納（連続3年未納時）：**
定款第9条に従い、理事会の議決を経て理事長が除名することができる。

③ 権限が制限され、又は資格が停止された会員は、未納の年会費を完納すれば従前の資格が復元される。除名された会員は、定款第5条に従い再入会しなければならない。

④ 特別な事由がある場合、理事会の承認により納付の猶予又は分割納付が可能である。

### 第8条（表具代規程）

① 入選以上の作品に対して表具代を課すものとし、表具は**協会が定めた標準オプション及び価格**により行う。

② 協会が提供する表具サービスは、機械裏打ち方式ではなく**手裏打ち方式**を原則として堅持する。

③ 表具代は**実際の表具原価に基づいて**算定し、会員には割引特典を提供する。

④ 作品規格別の表具代は次のとおりである。

| 作品規格           | 標準価格（非会員適用）  | 会員価格（正会員適用）  |

| 国展紙（70x200cm） | 作品1点当たり12万ウォン | 作品1点当たり10万ウォン |

### 第9条（図録代規程）

2. 追加購入又は展示に参加していない非会員の場合

| ------ | ------------------------- |

| 非会員 | 3万ウォン                 |

### 第10条（作家個人ホームページの初期構築費及び年間保守費規程）

① ホームページの制作及び保守契約を締結し、**年間保守費を納付した正会員**は、当該年度の年会費が免除される。

② 展示に40点以上の作品を出品した作家には、次の特典を提供する。

**ア. （初回特典）**
個人ホームページ制作費及び1年目の保守費を全額免除し、当該年度の年会費も免除する。

**イ. （継続特典）**
2年目からは**年間保守費のみ納付**すれば、ホームページの保守サービスを継続して提供され、**当該年度の年会費は免除**される。

③ 展示に30点以上出品した作家は、初期構築費が免除され、当該年度の年会費は免除される。

④ 展示に20点以上出品した作家は、初期構築費の50%を割り引く。

| 非会員 | 初期構築費700,000ウォン / 年間保守費300,000ウォン |

### 第11条（納付方法）

① すべての費用は、オンライン納付（口座振替、CMS引き落とし等）を原則とする。

② オンライン決済システムを通じて納付し、購入者が希望する場合は電子領収書の発行が可能でなければならない。

### 第12条（正会員の基本特典）

**① 正会員共通の特典**

ア. 展示会に参加する場合、図録1冊を無料で提供

イ. 出品料、表具代、図録代の割引価格を適用

ウ. 作家個人ホームページを構築する場合、年会費を免除

**② 推薦作家以上の追加特典**

ア. 招待作家候補への登録機会

イ. 特別展示会及び海外交流展への参加優先権

ウ. 要件充足時、作家個人ホームページの初期構築費の選別支援

**③ 招待作家以上の追加特典**

ア. 役員候補の推薦資格（定款第11条に従い総会で選出）

イ. 運営委員及び審査委員の資格（運営及び審査規程第3条）

**④ 役員特典**

ア. 運営委員及び審査委員の委嘱優先権

イ. 作家個人ホームページの初期構築費及び年間保守費の1年間免除

ウ. 招待作家展の出品料（当該展示の募集要項で定めた金額）の5%割引

### 第13条（高齢会員の特典）

満70歳以上で、加入期間が10年以上の会員のうち、協会の発展に寄与した功績が次の各号の基準により顕著と認められる場合は、理事会の審議を経て年会費免除の特典を付与することができる。

① 協会の主要展示会への5回以上の参加

② 協会主催のセミナー及びワークショップでの講演3回以上

③ 協会事業の企画及び実行における中核的な役割の遂行等

この際、功績の審議は別途設けられた「功績審査基準」に従って客観的に行い、必要に応じて「功績審査小委員会」を構成して評価することができる。

### 第14条（支部活動支援金）

① 協会は、毎年予算の範囲内で支部及び支会の活性化のための「支部活動支援金」を編成しなければならない。

② 支部が主催する地域公募展及び企画展は、本会の理事会の承認を経て「協会後援名称」を使用することができ、本会は、これに必要な広報及び審査委員の派遣を支援する。

③ 優秀な活動を行った支部については、年末の総会で表彰し、次年度の支援金を増額することができる。

## 附則 <2026. 1. 1.>

本規程は、理事会の議決を経て公布した日から施行する。

### 第2条（準用規定）

本規程に明示されていない事項は、理事会の議決に従う。

### 第3条（改正）

本規程は、定款第41条に従い理事会の議決により改正し、改正内容は次の総会に報告する。
