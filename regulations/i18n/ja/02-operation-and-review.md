# 運営及び審査規程

> [施行 2025. 2. 8.] [第3号施行令、2026. 1. 1.、一部改正]

### 第1条（目的）

本規程は、定款第41条に従い、社団法人 東洋書芸協会（以下「本会」という。）の運営委員及び審査委員の委嘱並びに審査方法等、展示運営全般に関する事項を定めることを目的とする。

### 第2条（構成及び任務）

① 運営委員は運営委員長及び運営委員で構成し、大韓民国東洋書芸大展の円滑な運営のために貢献しなければならない。

② 審査委員は審査委員長及び審査委員で構成し、大韓民国東洋書芸大展の公正な審査を通じて入賞作品を選定する。

### 第3条（資格）

本会の運営委員及び審査委員の資格は、次の各項のとおりとする。

① 本会の招待作家（諮問委員、顧問を含む）

② 他の書道団体の招待作家

③ 本会の顧問又は諮問委員が推薦した人士

### 第3条の2（審査委員の除斥、回避、忌避）

① 審査委員は、次の各号のいずれかに該当する場合、当該作品の審査から除斥される。

1. 審査委員が出品者の配偶者又は直系尊属・直系卑属である場合
2. 審査委員が出品者の師であるか、又は出品者が審査委員の弟子である場合（例：大学・大学院の指導教授等）
3. その他、公正な審査を期待しがたい明白な事由がある場合

② 審査委員は、第1項の事由がある場合、又は自ら公正な審査が困難であると判断される場合、審査委員長の許可を受けて当該作品の審査を回避することができる。

③ 出品者は、審査委員に第1項の事由がある場合、審査開始前までに書面で忌避を申請することができ、審査委員長がこれを決定する。

### 第3条の3（募集委員の資格）

本会の募集委員の資格は、次の各項のとおりとし、協会の展示に対する理解と広報活動への積極性を最優先に考慮する。

1. 本会の正会員として活動期間が1年以上であり、協会活動に積極的に参加した者
2. 美術又は芸術関連分野で3年以上の広報、マーケティング又は企画業務の経歴がある者
3. 本会の招待作家1名以上の推薦を受け、協会の発展に貢献する意思が明確であると認められた者
4. 本会主管の公募展又は展示に3回以上の出品実績がある作家

### 第4条（委嘱方法）

理事長は、大韓民国東洋書芸大展の開催1か月前に審査件数を基準として人員を定めるものとし、その2倍数を推薦し、理事会の議決を経て委嘱を決定して委嘱証書を授与する。

### 第4条の2（委員の手当及び報酬）

① 委員の報酬は、活動の性格に応じて手当及び旅費、実績インセンティブに区分して支給する。本委員は勤労関係ではない委嘱職であり、報酬は協会の財政状況及び内部規程に従い定める。

② 審査委員の報酬は、次の各号に従い支給する。

| 区分                 | 算定基準（1人当たりの提案金額） | 支給原則                                   |
| -------------------- | ------------------------------- | ------------------------------------------ |
| 審査手当（審査料）   | 15万ウォン（1日／半日）         | 審査の規模及び所要時間に応じて支給         |
| 原稿料（審査評）     | 10万ウォン（1件当たり）         | 審査評の作成時に別途支給                   |
| 旅費（交通費）       | 実費精算（KTX、高速バス等）     | 実費精算により支給                         |
| 食事代（昼食／夕食） | 2万ウォン（1食当たり）          | 審査日程に昼食又は夕食が含まれる場合に支給 |

③ 運営委員の報酬は、次の各号に従い支給する。

| 区分             | 算定基準（1人当たりの提案金額） | 支給原則                          |
| ---------------- | ------------------------------- | --------------------------------- |
| 会議出席手当     | 10万ウォン（1回当たり）         | 会議時間（2時間基準）に応じて支給 |
| 旅費（交通費）   | 実費精算（原則）                | 審査委員の基準を準用              |
| 食事代（必要時） | 2万ウォン（1食当たり）          | 会議時間に応じて支給              |

④ 募集委員のインセンティブは、募集実績に応じて次の表の区間別に支給し、募集委員としての会議出席等の基本活動手当とは別に合算して支給する。募集人数が30名に達した場合、1番目から30番目までを1人当たり10,000ウォンとして計算し、31番目からは当該区間の単価を加算する。

| 区分           | 募集人数（名） | 支給基準                               | 支給額（累計）           |
| -------------- | -------------- | -------------------------------------- | ------------------------ |
| Tier 4（深化） | 1〜29名        | 1人当たり5,000ウォン                   | 人数 × 5,000ウォン       |
| Tier 3（熟練） | 30名           | 1〜30番目 1人当たり10,000ウォン        | 300,000ウォン            |
| Tier 2（優秀） | 31〜40名       | 31〜40番目 1人当たり12,000ウォンを追加 | 40名の場合 420,000ウォン |
| Tier 1（最上） | 41名以上       | 41番目から1人当たり15,000ウォンを追加  | 50名の場合 570,000ウォン |

⑤ 運営委員、審査委員、募集委員等を兼職する場合、活動日及び役割の性格が異なるときは、各項目の手当を合算して支給することを原則とする。ただし、**審査委員が募集活動を兼職した場合**、本人が募集した出品者が当該公募展の審査対象に含まれているときは、**当該審査委員を募集インセンティブの支給対象から除外するか、当該出品作の審査から必ず除斥**しなければならない。

### 第5条（審査部門及び規格）

大韓民国東洋書芸大展の公募作品の規格は、**国展紙（70×200cm）、全紙（70×136cm）、半切（35×136cm）**とし、公募部門は次のとおり5部門とする。必要な場合には、理事会の議決を経て審査部門を追加することができる。

① ハングル（ハングル正字・正字混用・ハングル半草書・半草書混用・ハングル真草書・版本体、民体等）

② 漢文（甲骨・金文・篆書・隷書・楷書・行書・草書）

③ 現代書道・カリグラフィー（現代韓国画を含む）

④ 篆刻・書刻（木刻・石刻を含む）

⑤ 文人画、東洋画、彩色画、水墨画、民画

### 第6条（審査）

① 古い法帖を基準として作品を選定するが、書体ごとの構成、余白、調和、墨色に重点を置いて作品性の優劣を決定する。

② 点画・結構・章法・調和の完成美を審査するが、次の表の諸要素を比較して審査する。

|              |              |              |              |
| ------------ | ------------ | ------------ | ------------ |
| 点画（點劃） | 結構（結構） | 章法（章法） | 調和（調和） |
| 方円         | 大小         | 濃淡         | 気韻         |
| 曲直         | 疎密         | 剛柔         | 雅俗         |
| 軽重         | 虚実         | 緩急         | 美醜         |
| 蔵露         | 向背         | 余白         | 通変         |
| 形質         | 呼応         | 構成         | 創新         |

③ 審査計画及び準備

ア. 審査委員長は、審査開始前に［別表1］審査計画書を作成し、次の事項を明示する。

1. 審査日程及び進行方式
2. 部門別の審査委員の構成
3. 評価基準の詳細な適用方案
4. 作品の展示及び検討方式

イ. 受け付けた作品には審査番号を付与し、作家情報を封印して匿名性を保障する。

ウ. 審査委員長は、審査前に評価基準について事前教育を実施する。

④ 審査の進行及び評価方式

ア. 各審査委員は［別表2］審査表を使用し、各項目の配点は次のとおりである。

1. 点画（點劃）：25点（評価要素：方円、曲直、軽重、蔵露、形質等）
2. 結構：25点（評価要素：大小、疎密、虚実、向背、呼応等）
3. 章法：25点（評価要素：濃淡、剛柔、緩急、余白、構成等）
4. 調和：25点（評価要素：気韻、雅俗、美醜、通変、創新等）

イ. 評価は5点単位で採点し、各項目の評価根拠を簡潔に記載する。

ウ. 審査委員別の総点を算出し、最高点と最低点を除いた平均点を最終点数とする。

⑤ 審査意見の作成

ア. 審査完了後、各審査委員は［別表3］審査意見書を作成する。

1. ハングル部門の審査評
2. 漢文部門の審査評
3. 現代書道・カリグラフィー部門の審査評
4. 篆刻・書刻部門の審査評
5. 文人画、東洋画、彩色画、水墨画、民画部門の審査評
6. 総合審査評及び改善提案

イ. ［別表3］審査意見書には、出品作の全般的水準、特徴的傾向、優秀作品の特性等を含む。

⑥ 総合評価及び結果集計

ア. 審査委員長は、［別表4］審査結果総合表を取りまとめ、次の事項を整理する。

1. 作品別の審査委員評価点数
2. 最終平均点の算出
3. 順位及び等級の決定

イ. 等級決定基準

1. 90点以上：大賞及び最優秀賞の候補
2. 85点以上：優秀賞の候補
3. 80点以上：特選の候補
4. 75点以上：入選の候補

ウ. 同点者が生じた場合の処理方案

1. 調和の点数が高い作品を優先
2. 章法の点数が高い作品を優先
3. 審査委員間の協議による決定

エ. 大賞の選定：90点以上を獲得した作品が2点以上の場合、審査委員全員の投票を経て最終的に大賞を決定する。

⑦ 審査結果の確定

ア. 審査委員長は、総合審査結果を理事長に報告する。

イ. 理事会は審査結果を検討し、最終承認する。

ウ. 確定した審査結果は受賞者に個別に通知し、協会ホームページに掲示する。

エ. 審査委員は、特選以上の受賞作（本賞・特別賞・特選）について、50字程度の「審査評（Key-point
Feedback）」を作成しなければならず、協会は作家が本人の審査点数表と審査評をオンラインで照会できるようシステムを提供する。

### 第7条（入賞内訳及び賞金）

① 第6条の審査結果に従って選定された入賞作に対して、次のとおり表彰する。

② 第6条の審査結果による入賞等級は、**本賞、特別賞、特選及び入選**に区分する。

③ 各入賞等級別の詳細な内訳、選定人数及び賞金は、次のとおりである。

**ア. 本賞（作品の芸術性を最優先の基準として選定）**

- 大賞：1名、賞状及び賞金200万ウォン
- 最優秀賞：1名、賞状及び賞金100万ウォン
- 優秀賞：2名、賞状及び賞金30万ウォン

**イ. 特別賞（書の均衡ある研究と多体（多書体）出品の奨励）**

- 五体賞：3名、賞状及び賞金20万ウォン
- 三体賞：4名、賞状及び賞金15万ウォン

**ウ. その他の入賞**

- 特選：30名（調整可能）、賞状
- 入選：50名（調整可能）、賞状

④ 第3項の特別賞は、複数の書体に対する作家の多角的な努力と研究を奨励する協会の運営方針を反映して定める。

⑤ 第3項に明示された表彰人数（特選、入選を含む）は、当該年度の出品作の総数及び作品の全般的水準を考慮して、理事会の議決により調整することができる。

⑥ 第3項以外に、協会の財政状況又は特別な後援の誘致があった場合には、理事会の議決を経て追加の特別賞（例：後援社賞、理事長賞等）を新設して表彰することができる。

⑦ 賞金に課される諸税及び公課金は、受賞者本人の負担を原則とする。

⑧ 表彰式及び賞金支給に関する詳細な手続は、理事長が別途定めて公示する。

### 第8条（任期）

**運営委員及び審査委員の任期は、委嘱日から当該年度の大韓民国東洋書芸大展の終了日までとする。**
ただし、異議申立て処理規程に従って受け付けられた異議申立ての再検証業務は、その処理が終わるまで遂行する。

### 第9条（総会議案の事前公開及び意見聴取）

① 理事会は、総会に上程する主要議案を開催7日前までに協会ホームページ及びオンラインチャネルを通じて**全会員（準会員を含む）**に公開しなければならない。

② 協会は、オンラインのコメント又は電子アンケートの機能を提供し、等級にかかわらずすべての会員が議案について意見を述べることができるようにする。

③ 理事会は、総会において第2項を通じて収集された会員の主要な意見を義務的に報告しなければならない。
