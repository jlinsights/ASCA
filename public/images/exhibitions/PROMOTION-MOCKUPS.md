# 전시 홍보 게재 목업

`promotion-demo-1.png`부터 `promotion-demo-3.png`는 2026-11-08 사용자의 요청에
따라 imagegen으로 제작한 가상 개인전·단체전·온라인전 포스터다. 실제 작가·장소·
일정·의뢰 광고를 나타내지 않는다. 포스터와 화면 모두 예시임을 표시한다.

실제 전시 목록·건수·연혁에는 포함하지 않는다. 확인된 외부 전시는 별도의
`app/exhibitions/_data/exhibition-listings.ts`의 승인 자료로 관리한다. 유관업체
광고 영역도 현재는 광고주 없는 게재 예시다. 향후 실제 광고를 게재할 때에는 소재
권한·계약·기간·광고 표시와 사무국 검토가 필요하다.
