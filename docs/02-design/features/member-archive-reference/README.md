# ASCA 회원 작가 아카이브 — 1단계 기획 (v0.2, 2026-10-18)

> 화면 작업용 참고 문서. 시안 이미지의 데이터는 모두 가상이다. DB 구조의 기준은
> J의 데이터 구조 초안과 1단계 DB PR이다.

## 목적

협회가 주최하는 공모전·전시 기록을 바탕으로 회원 작가의 작품과 이력을 협회 인증
형태로 한곳에 모은다. 작가는 정리된 포트폴리오를 얻고, 협회는 2단계 공모전
온라인 접수의 기반 데이터를 확보한다.

## 확정된 결정

- 위치: orientalcalligraphy.org는 그대로 두고 서브도메인(예:
  `artists.orientalcalligraphy.org`)으로 운영. 같은 저장소·같은 Supabase DB,
  Next.js middleware로 라우팅.
- 이미지: Supabase Storage(Pro). 공개 버킷(썸네일·웹용)과 비공개 버킷(원본).
  업로드 때 크기별로 만들어 두고 이미지 변환 기능은 쓰지 않는다.
- 연락처는 공개 화면에 절대 노출하지 않는다. 문의는 협회를 거친다.

## 아직 결정 대기

- 공개 대상: 전체 회원 / 초대·추천작가 먼저
- 초기 입력 범위: 최근 몇 회 공모전까지 소급할지

## 1단계 범위

포함

- 작가 목록: 아호·이름 검색, 서체·등급(초대·추천·회원) 필터
- 작가 프로필: 아호, 서체, 사사, 소속, 소개, 수상·전시 이력, 인증 배지
- 작품 상세: 사진, 석문·풀이, 영문, 규격·재료·낙관, 출품 기록
- 작품 등록: 작가 본인 또는 협회 대리 입력, 게시 상태 초안 → 검토 대기 → 게시
- 협회 관리자의 인증 승인

제외 (2·3단계): 공모전 온라인 접수·심사, 작품 판매·결제, 프라이빗 뷰잉룸, 전시
예약(기존 Luma 페이지 연결로 대체)

## 디자인 기준 (시안 기준값)

- 배경 한지색 `#FAF7F0`, 포인트 낙관 빨강 `#b8392f`
- 제목·작가명: Gowun Batang(세리프), 본문: Gothic A1
- 작품 속 한자 표기: Noto Serif CJK KR 900 (서예 웹폰트 다수가 번체 한자를
  지원하지 않음)
- 작품 이미지는 잘라내지 않고 비율 유지(세로 족자, 가로 횡액 모두)

## 운영 원칙

- 초기 데이터는 협회가 채운다: 역대 공모전 수상 명단과 도록을 먼저 입력해 작가가
  처음 들어왔을 때 이력이 이미 있게 한다.
- 인증은 협회 기록 기준: 협회 행사 이력은 자동 인증, 외부 이력은 증빙 확인 후
  인증. 인증 플래그 변경과 게시는 관리자만.
