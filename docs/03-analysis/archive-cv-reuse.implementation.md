# 공개 CV·PDF 인쇄와 전시 작품 재사용

## 공개 이력

작가 프로필의 ‘공개 이력 · CV / PDF’에서 `/archive/artists/[id]/cv`로 이동한다.
공개 프로필과 공개 가능한 `artist_records`만 anon 자격 증명과 기존 RLS로
조회한다. 연도별 정렬, 수상·전시·출품·인증 유형 선택, 협회 확인 이력만 보기
기능을 제공한다. 기록 출처와 협회 확인 여부는 별개로 표시한다. 출처가 협회
아카이브라는 이유만으로 인증 이력으로 취급하지 않는다. 개인 연락처, Clerk ID,
이미지 원본 경로는 조회하지 않는다.

PostgREST의 기본 행 제한을 넘는 이력도 나누어 읽는다. 안전 상한에 도달해 전체를
읽지 못하면 명시적으로 알리고 인쇄를 막아 불완전한 이력을 전체 CV로 내보내지
않는다.

PDF는 브라우저의 ‘인쇄 / PDF 저장’을 사용한다. 글꼴 로딩을 기다린 뒤 인쇄 창을
열며, 출력에는 현재 선택한 유형·확인 여부를 표시한다. 출력용 A4 스타일은 사이트
내비게이션과 조작 버튼을 숨기고, 한글·한자와 기록별 출처·확인 표시는 유지한다.
CV는 공개 기록의 정리이며 협회 발급 증명서가 아니다. 서버 PDF 생성 서비스나 파일
저장·전송은 추가하지 않는다.

## 전시 작품 재사용

- 관리: `/admin/archive/exhibitions`에서 기존 CMS 전시를 선택한다.
- 작품 선택: 공개 작가의 게시된 작품을 검색해 연결한다.
- 연결 해제: 이후 작품이나 작가가 비공개가 되어도 관리자는 기존 연결을 해제할 수
  있다.
- 공개: `/archive/exhibitions`와 상세 페이지에서 공개 전시의 공개 작품만
  조회한다.

연결 API는 기존 `exhibition_artworks`에 전시 ID·작품 ID만 기록한다. 재시도는
기존 유일 제약과 중복 무시 upsert로 처리하며, 이미 연결된 행의 설명이나 순서는
덮어쓰지 않는다. 해제는 연결 행만 삭제하고 원본 작품·사진·이력은 보존한다.
갤러리는 원본 작품·작가·이미지를 조인해 읽으므로 작품 제목을 고치면 다음 조회에
반영된다. 출품 이력이나 협회 인증을 자동 생성하지 않고, `exhibition_artists`의
역할도 변경하지 않는다.

기존 연혁 기반 전시와 고정 전시 데이터를 DB 전시로 변환하거나 교체하지 않는다.
CMS 전시가 없으면 빈 상태를 표시한다. 관리 페이지와 쓰기 API는 Clerk 관리자
권한을 서버에서 확인하고 출처·속도·입력 검증과 감사 기록을 적용한다. 공개
갤러리의 최종 접근 범위는 기존 전시·작품·작가 RLS가 강제한다.

## 검증과 배포

로컬 공개 조회 검사는 이력의 기본 행 제한 초과, 비공개 기록 제외, 전시 비공개,
게시 취소·비공개 작가 작품 제외, 원본 제목 변경 반영을 확인하고 테스트 데이터만
삭제한다. 같은 스크립트가 기존 Archive database CI에서 실행된다. 컴포넌트 검사는
CV 필터와 인쇄 호출, 불완전한 CV의 인쇄 차단, 작품 ID 재사용, 실패 시 검색
유지와 비공개 작품 연결 해제를 검증한다.

이번 단계의 추가 DB 마이그레이션은 없다. 작업 브랜치 전체를 배포하려면 이전
단계의 검토 워크플로 마이그레이션을 먼저 적용해야 한다. 운영 데이터·배포 설정은
변경하지 않는다. 관리자 실제 계정의 전시 연결 조작은 별도 브라우저 검증이
필요하다.

공개 CV는 gstack으로 지원 언어별 모바일 화면의 번역과 가로 넘침을 확인했다. 실제
A4 PDF를 생성해 한글·한자, 선택한 이력만 출력되는지, 조작 버튼이 숨겨지는지,
짧은 CV 뒤에 빈 페이지가 생기지 않는지 검사했다. 검증용 자료는 로컬 DB에만
사용한다.

검증 중 webpack 캐시 때문에 새 간격 클래스가 CSS 산출물에 누락되는 문제를
확인했다. `build:full`에서 webpack 캐시를 먼저 정리하도록 수정하고, 재빌드한
CSS와 브라우저의 실제 간격을 확인했다. 기존 디자인 토큰은 변경하지 않는다.
